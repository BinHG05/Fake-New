📊 Phase 1–2: Thu Thập & Xử Lý Dữ Liệu

Nguồn dữ liệu

  • Fakeddit dataset (Reddit-based, 6-class labels)
  • Crawl bổ sung từ Reddit API (5 subreddit)
  • Comment tree đệ quy (DFS parse)
  • Label Studio annotation (Human-in-the-loop)

Pipeline xử lý

  • Text: Regex cleaning, Unicode normalize
  • Image: Resize 224×224, ImageNet normalization
  • Embedding: XLM-R (768d) + ResNet50 (512d)
  • Graph: NetworkX → PyG Data (.pt files)

⚙️ Các Kỹ Thuật Nổi Bật

🧠 Deep Learning & NLP

  • XLM-RoBERTa — text embedding đa ngôn ngữ (768d)
  • ResNet50 — image embedding (2048d → 512d)
  • Multi-Head Cross-Attention (4 heads)
  • Gated Residual + Sigmoid Gate
  • Layer Normalization + Dropout

🔗 Graph Neural Networks

  • GraphSAGE — neighbor aggregation
  • GAT — attention-weighted message passing
  • GCN — spectral convolution
  • Global Mean Pooling (graph → vector)
  • Residual connections giữa GNN layers

📐 Training Strategies

  • Balanced Class Weights (Cost-sensitive)
  • Early Stopping (patience=15)
  • Multi-seed evaluation (5 seeds)
  • Ablation Study (6 biến thể)
  • Gradient Clipping (max_norm=1.0)

🛠️ Data Engineering

  • Reddit API + DFS comment tree
  • Label Studio — human annotation
  • Batch Pipeline Automation (.bat)
  • DVC — data version control
  • Schema validation rules

🗓️ Kế Hoạch Tiếp Theo & Hạn Chế

⚠️ Hạn chế hiện tại

  • 6-Class F1 còn thấp (~0.17)
    → Class imbalance nghiêm trọng (TRUE: 44% vs BARELY_TRUE: 3%)
  • Image coverage thấp (16.9%)
    → Chỉ 402/2,384 bài có ảnh, hạn chế khả năng học visual features
  • Dataset nhỏ (2,384 samples)
    → Chưa đủ đại diện; cần mở rộng để có kết quả chính thức

🔮 Hướng phát triển

  • Mở rộng dữ liệu: thu thập thêm bài có ảnh
  • Thử Focal Loss / Oversampling cho class imbalance
  • Fine-tune XLM-R (unfreeze last layers)
  • Temporal modeling (thời gian lan truyền)
  • Heterogeneous GNN (phân biệt post vs comment)
  • CLIP thay thế ResNet50 cho cross-modal alignment
