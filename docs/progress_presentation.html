🧠 Tại Sao Dùng CLIP? — Đột Phá Cốt Lõi

CLIP (Contrastive Language-Image Pre-training) — OpenAI — Trained on 400M image-text pairs

❌ Trước đây (Phase 3 — Baseline)

  • Text: XLM-RoBERTa chỉ hiểu ngữ nghĩa văn bản
    → Không biết "chữ" này liên quan đến "ảnh" nào
  • Image: ResNet50 chỉ trích xuất đặc trưng thị giác
    → Không hiểu ý nghĩa ngữ cảnh của bức ảnh
  • Kết quả: 63.2% Accuracy
    → Text và Image "nói chuyện khác ngôn ngữ"

✅ Hiện tại (Phase 4 — CLIP)

  • CLIP Text: Hiểu chữ qua "lăng kính hình ảnh"
    → Đọc "chiến tranh" → tự liên tưởng tới hình ảnh chiến tranh
  • CLIP Image: Hiểu ảnh qua "lăng kính ngôn ngữ"
    → Nhìn ảnh phim trường → biết đó không phải chiến tranh thật
  • Mismatch Detection: 88.9% Accuracy
    → Phát hiện khi "chữ nói một đằng, ảnh nói một nẻo"

Bí quyết: CLIP tạo ra một không gian chung (shared embedding space) cho cả Text lẫn Image, giúp model phát hiện sự "lệch pha" — dấu hiệu then chốt của tin giả.

🔑 Phân tích lỗi

  • ✅ REAL recall cao (91%)
    Model rất giỏi nhận diện tin thật — Chỉ 9% tin thật bị gán nhầm là giả
  • ⚠️ FAKE recall 83%
    17% tin giả bị "lọt sổ" — Tin giả tinh vi gần giống tin thật
  • 💡 Content v2 > GNN v3
    Chứng minh: Nội dung (Text+Ảnh) là tín hiệu mạnh nhất. GNN cung cấp thêm context nhưng không vượt qua
  • 🔬 Lý do GNN thấp hơn 1.4%
    Cascade graph nhỏ (ít comment) → GNN thiếu tín hiệu cấu trúc, sinh noise

⚙️ Các Kỹ Thuật Nổi Bật

🧠 Feature Extraction (v2)

  • CLIP ViT-B/32 — Text (512d) + Image (512d)
  • XLM-RoBERTa — đa ngôn ngữ context (768d)
  • Cosine Mismatch Score — Text↔Image (1d)
  • Gated Expert Fusion — 3 chuyên gia + Attention Gate
  • 🆕 Feature Injection vào cascade graphs (1793d/node)

🔗 Graph Neural Networks (v3)

  • Cross-Attention Fusion (4 heads, gated residual)
  • GAT — attention-weighted message passing
  • GraphSAGE — neighbor aggregation
  • Global Mean Pooling (graph → vector)
  • Residual connections giữa GNN layers

📐 Training Strategies

  • Balanced Class Weights (Cost-sensitive)
  • Early Stopping (patience=15)
  • Weight Decay regularization
  • Gradient Clipping (max_norm=1.0)
  • Dropout 0.3 toàn pipeline

🛠️ Data Engineering

  • Reddit API + DFS comment tree
  • Label Studio — human annotation
  • 🆕 Auto image recovery (media_url extraction)
  • DVC — data version control
  • Flask Dashboard — full pipeline automation

🗓️ Hạn Chế & Hướng Phát Triển

⚠️ Hạn chế hiện tại

  • Dataset nhỏ (2,384 samples)
    → Có dấu hiệu overfitting; cần mở rộng để xác nhận tính tổng quát
  • Cascade graph ngắn
    → Nhiều bài chỉ có 1-2 comment, GNN thiếu "thức ăn" để học pattern
  • GNN v3 < Content v2 (1.4%)
    → Graph structure chưa bổ sung đủ tín hiệu; cần thiết kế GNN tốt hơn

🔮 Hướng phát triển

  • Mở rộng dataset: crawl thêm bài có cascade dài
  • Heterogeneous GNN (phân biệt post vs comment)
  • Temporal modeling (thời gian lan truyền)
  • Fine-tune CLIP encoder cho domain Reddit
  • Data augmentation cho lớp thiểu số (FAKE)
